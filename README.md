# Power-BI-Sales-Analytics-Dashboard

## Project Overview
Developed an interactive two-page Sales Analytics Dashboard
using Microsoft Power BI to analyze sales performance,
revenue trends, customer performance, and market-wise sales.

## Dashboard Features

### Page 1: Sales Overview
- Total Revenue KPI
- Sales Quantity KPI
- Revenue by Customer
- Sales Quantity by Customer
- Revenue Trend Analysis
- Date-based filtering

### Page 2: Market Analysis
- Revenue by Market
- Sales Quantity by Market
- Top 5 Customers
- Top Products
- Interactive filtering
